01 — About

Practical IT work, done properly

My approach is methodical rather than dramatic: understand the symptom, isolate the cause, apply the smallest correct fix, then document it so the problem is easier next time.

I work across the everyday layers of computing. That means taking apart and rebuilding PCs, testing memory and storage, checking power supplies and thermals, and replacing parts only when the evidence says they are at fault. It also means installing and configuring Windows and Linux, managing drivers and user accounts, tuning startup and storage, and recovering systems that no longer boot.

Beyond the desktop, I configure routers and IP settings, trace connectivity problems with ping, traceroute and DNS lookups, and explain what is happening in plain language. I write scripts in Python, Bash and PowerShell to automate repetitive work, and I build responsive websites when a task needs one.

On the security side, I focus on fundamentals and defence: password and authentication hygiene, system hardening, log review, vulnerability awareness, and testing in my own home lab or on systems I have written permission to assess. Security testing is performed only with proper authorization. I do not offer access to systems I do not own or have permission to test, and I document findings so they can be fixed.

04 — Services

What I can help with

Everyday IT problems, hands-on configuration, and small development tasks. If a job falls outside my experience, I will say so rather than guess.

Hardware and software diagnosis, fault isolation, and problem resolution on desktops and laptops.

Starts with reproducing the fault and recording the symptoms, then narrowing down whether it is power, storage, memory, drivers, or software. You get a written summary of what was tested and what changed.

Installation, configuration, optimisation, updates, driver setup, and troubleshooting for Windows and Linux.

Clean installation or repair of an existing system, including drivers, updates, user accounts, and a sensible starting configuration. Dual-boot setups and recovery from a system that will not start are both covered.

Assembly, component upgrades, driver installation, system configuration, cleaning, and preventive maintenance.

Builds and upgrades are tested before handover, and maintenance includes dust removal, thermal checks, cable management, and a review of startup items so the machine stays reliable.

Installation and configuration of legitimate software, including dependency, permission, and compatibility checks.

Licensed and open-source software only. I check system requirements, resolve dependency or permission errors, and confirm the application actually runs before I call the job finished.

Startup, storage, and configuration improvements to make an existing machine responsive again.

Aimed at machines that have become slow rather than broken: startup load, background services, free disk space, and settings that quietly cost performance. No promises about numbers I cannot measure.

LAN and Wi-Fi troubleshooting, IP configuration, DNS and DHCP checks, router configuration, and connectivity testing.

Connectivity problems are traced layer by layer: link, addressing, name resolution, then routing. You get an explanation of what was actually wrong, not just that it works now.

Responsive websites and technical web interfaces built with HTML, CSS, and JavaScript.

Static and lightly interactive sites that load quickly on mobile connections, work without a backend, and stay accessible by keyboard and screen reader.

Small applications and scripts for legitimate automation, file handling, reporting, and repetitive tasks.

Typically Python, Bash, or PowerShell scripts for maintenance and reporting, written with logging and a dry-run mode so nothing changes on your system without warning.

Security awareness guidance, configuration review, vulnerability identification, log review, and authorized security testing — performed only with written permission.

Defensive work: hardening advice, account and password hygiene, update strategy, and review of configuration and logs. Any testing is limited to systems you own or have written permission to assess, and findings come with remediation guidance rather than exploit code.
